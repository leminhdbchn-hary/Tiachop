# Ảnh ô tô cho game

Up ảnh vào thư mục này (Add file → Upload files). Đặt tên file:

`tên tiếng Việt__English.jpg` — ví dụ `xe tải__truck.jpg`, `xe cứu hỏa__fire truck.jpg`.

Chỉ cần tên tiếng Việt cũng được (`xe buýt.jpg`). Cần ít nhất 3 ảnh để game có câu hỏi ảnh.
Sau khi up, GitHub tự thu nhỏ ảnh, tạo giọng đọc và cập nhật game (khoảng 3–4 phút).
