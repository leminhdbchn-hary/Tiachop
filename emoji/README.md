# Emoji 3D

Ảnh emoji 3D từ bộ **Microsoft Fluent Emoji** (https://github.com/microsoft/fluentui-emoji), giấy phép MIT (xem `LICENSE`).
Tên file là mã Unicode của emoji (bỏ FE0F), ví dụ `1f436.webp` = 🐶. Đã chuyển sang WebP 256px cho nhẹ.
`index.html` tự đổi emoji trên màn hình thành các ảnh này; emoji không có ảnh thì giữ nguyên.
